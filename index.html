THE METHOD

Read shapes, not values.

Payload Radar compares the structure observed across your samples: field paths, types, presence, and array items. It helps you spot changes that deserve a closer look before a release.

01

Bring more than one sample

Choose JSON Lines for one JSON value per non-empty line. Choose JSON for a single document; a top-level array remains one document, and its items are analyzed together.

02

Evidence has limits

An observed field is not a guaranteed contract. Missing fields, small samples, and empty arrays can limit what we know. Review the evidence alongside your API specification.

03

Your data stays yours

Analysis happens in this browser. No payloads are sent to a server. Reports contain field paths, types and counts, but no raw sample values. Review field names before sharing.
